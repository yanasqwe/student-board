# Student Board · НМПЗ-21

Особистий розклад пар для групи НМПЗ-21: обираєш себе зі списку — бачиш тільки свої пари (загальні + вибіркові), викладачів, заліки та посилання на Zoom.

## Запуск локально

```bash
python3 -m http.server 5173
```

і відкрити http://127.0.0.1:5173/

## Дані

Усе в `data.js`:
- `SCHEDULE` — розклад (за київським часом, сайт сам переводить у пояс користувача);
- `SUBJECTS` — дисципліни, викладачі, списки студентів на вибіркових, Zoom-посилання;
- `TEACHERS` — контакти викладачів.

## Оновлення

Після змін у `data.js` / `app.js` / `styles.css` онови мітку версії `?v=...` в `index.html` — інакше браузери можуть до 10 хв тримати старі файли з кешу.
